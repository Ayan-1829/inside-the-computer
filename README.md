# Inside the Computer

**🔗 Live site: [ayan-1829.github.io/inside-the-computer](https://ayan-1829.github.io/inside-the-computer/)**

An interactive, zoomable tour of a whole desktop computer — click into any part to go deeper, from the case, through the motherboard, CPU and ALU, all the way down to individual logic gates and real chips.

## What's inside

- **A full computer, zoomable to any depth.** Start at the desk and click into the tower, then the motherboard, then the CPU, then the ALU, then a single logic gate — each level has its own diagram and explanation, with a breadcrumb and an overview map to jump anywhere directly.
- **34 real chips**, each with a datasheet-style pin diagram and an "Inside the chip" view: processors, memory, firmware, timing, bus, ALU, shifter, voltage regulator, audio and serial chips.
- **A working Intel 8086 emulator.** Pick an example program (or write your own 8086 assembly) and step through it instruction by instruction, watching a bright dot carry data along the address, data and control buses while every register, flag and memory location updates in step. It covers every documented 8086 instruction, all addressing modes, string operations, and DOS text output through `INT 21h`.
- **Live circuits you can operate**, not just diagrams: single logic gates with truth tables, a full adder that steps through its own gates one at a time, a 4-bit ALU with all nine operations, an 8-bit barrel shifter, a 4-bit comparator, and a fetch-decode-execute walkthrough.
- **Parts you can drag around** on the desk and motherboard views, to see what's underneath.
- Built for **keyboard and touch** as well as mouse: every part and control is reachable by keyboard, phones get large tap targets and a part list, and reduced-motion preferences are respected.
- **Light and dark themes**, remembered between visits.

## Who it's for

Anyone curious about what's actually happening inside the computer they're using right now — students, hobbyists, and anyone who's ever wondered what a CPU, an ALU, or a chip's pinout really looks like underneath the abstraction.
